# Cluster Theory

Single-wallet alerts are easy to overfit. A cluster asks for independent confirmation:

- Distinct wallets, not repeated buys from one wallet.
- A short time window.
- A combined wallet score floor, not only wallet count.
- Token and risk enrichment before alerting.

This improves signal hygiene, but it does not remove market risk. Treat every cluster as a research prompt and paper-trade first.
